# The Cozy Cup Café ☕

A warm and cozy café website built with HTML, CSS, and JavaScript.

## Pages / Sections
- Hero — Welcome banner with CTA
- About — Café story and stats
- Menu — Drinks, Food, Desserts (tabbed)
- Gallery — Visual showcase
- Contact — Address, hours, and message form

## How to Run
Just open `index.html` in your browser — no setup needed.
